# Product Roadmap

The authoritative high-level roadmap is [`/ROADMAP.md`](../../ROADMAP.md), and the detailed
acceptance ledger is [`IMPLEMENTATION_57_POINTS.md`](IMPLEMENTATION_57_POINTS.md).

Core server/web/desktop agents, NMS/Syslog, native mobile clients, BLE provisioning, ESP32
software, retention/capacity tooling, explainable RCA and ecosystem readiness are implemented.
Remaining non-deferred work is external acceptance evidence: sustained scale/soak runs,
provider-backed mobile distribution/push checks and physical ESP32/mobile HIL validation.
