# Product Specification

DeviceMesh helps an operator discover, inventory and observe devices on networks they control.

## V1 outcomes
- Know which devices exist and whether they are online.
- Enroll a Windows agent safely for richer telemetry.
- Inspect CPU, memory, disk and network metrics.
- Understand changes through a device event timeline.
- Receive threshold alerts.
- Run the full platform locally with Docker Compose.

## Non-goals for V1
Remote shell, arbitrary process execution, internet-wide scanning and autonomous remediation are intentionally excluded.
