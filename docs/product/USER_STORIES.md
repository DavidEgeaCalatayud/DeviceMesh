# User Stories

- As an operator, I can discover devices on a network I manage.
- As an operator, I can distinguish stable devices from transient IP addresses.
- As an operator, I can enroll an agent using a short-lived token.
- As an operator, I can see current host telemetry and recent history.
- As an operator, I can see when a device came online, went offline or changed identity attributes.
- As an operator, I can define a simple threshold alert and see when it fires.
