# System Context

## Actors

- **Operator**: owns or administers the monitored network.
- **Managed device**: a discovered network device, with or without an agent.
- **Agent**: trusted software installed on a device to provide rich telemetry.
- **Probe**: a passive/active network observation node such as an ESP32 or host probe.

## External systems

DeviceMesh requires no cloud service for core operation. Optional integrations must be adapters behind explicit interfaces.
