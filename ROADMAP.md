# DeviceMesh Roadmap

## V1 — Core platform
- FastAPI API and PostgreSQL persistence
- LAN discovery and stable device identity model
- Windows agent enrollment, heartbeat and telemetry
- Web dashboard, realtime state and event timeline
- Threshold alerts
- Docker Compose deployment
- Unit, integration, contract and E2E quality gates

## V2 — Mobile and operations
- Android dashboard and alert client
- Advanced operations/backup flows
- Improved topology and diagnostics

## V3 — Edge
- ESP32 probe, BLE provisioning and sensor telemetry

## V4 — iOS
- SwiftUI client and BLE provisioning

## V5 — Intelligence
- Baselines, anomaly detection and richer alert rules
- OpenTelemetry and production-scale observability
